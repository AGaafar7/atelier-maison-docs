# Troubleshooting

## Theme upload fails

- Confirm that you selected the complete Atelier Maison ZIP package.
- Do not upload the uncompressed project folder.
- Try uploading the ZIP again from **Online Store → Themes**.
- If Shopify reports a specific validation error, record the full message before contacting support.

## Images do not appear

- Confirm that an image has been selected in the relevant section setting.
- Check that the image is available in Shopify's file or product media library.
- Preview the storefront again after saving.

## Navigation links are missing

- Create or update menus under **Content → Menus** in Shopify admin.
- Select the intended menu in the header or footer section settings.
- Save the theme editor.

## Collection filters are missing

- Enable collection filters in the collection section settings.
- Configure the filters available to your store through Shopify's Search & Discovery functionality.
- Confirm that the collection contains products with the relevant filterable data.

## Changes are not visible

- Save changes in the theme editor.
- Confirm that you are previewing the correct theme.
- Check whether you are viewing a published theme or an unpublished theme preview.

## Still need help?

Visit the [Support page](support) and include your theme version, affected page, browser, and steps to reproduce the issue.
