# Atelier Maison support

For help with installation, configuration, or a possible theme issue, open a support request through the official repository:

[Contact Atelier Maison support](https://github.com/AGaafar7/atelier-maison-docs/issues/new)

Please include:

- Theme version.
- Shopify store URL (do not share passwords or private credentials).
- The page or section affected.
- A clear description of the problem.
- Steps to reproduce the issue.
- Screenshots where useful.

Do not include customer personal data, payment details, passwords, API keys, or access tokens in a support request.

Support requests are handled by the theme developer. Shopify platform, billing, and account issues should be directed to [Shopify Support](https://help.shopify.com/).
