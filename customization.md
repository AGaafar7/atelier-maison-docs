# Global customization

Open **Online Store → Themes → Customize**. Use the theme editor's **Theme settings** area to configure the global design system.

## Typography

Atelier Maison provides separate font controls:

- **Heading font:** Work Sans 600 by default.
- **Body font:** Inter 400 by default.

Choose fonts that suit your brand and remain readable across desktop and mobile devices.

## Layout

- **Page width:** Narrow (90rem) or Wide (110rem).
- **Page margin:** Default 48, adjustable from 16 to 64 in increments of 2.

## Colors

The default color palette is:

| Setting | Default |
|---|---|
| Background | `#F7F5F0` |
| Foreground | `#171717` |
| Surface | `#EEEAE2` |
| Accent | `#111827` |
| Muted | `#6B6761` |
| Border | `#DEDAD2` |

Use the theme editor's color controls to adapt the palette to your brand. Check text contrast after changing colors.

## Input corner radius

The default input corner radius is 0. The available range is 0–10.

## Save your changes

Select **Save** in the Shopify theme editor after making changes. Preview important pages at desktop and mobile widths.
