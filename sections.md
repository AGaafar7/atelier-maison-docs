# Sections and homepage

Atelier Maison's default homepage is arranged in this order:

1. Maison editorial hero
2. Featured collections
3. Maison new arrivals
4. Maison brand story
5. Maison lookbook
6. Maison newsletter

You can add, remove, reorder, and configure sections through the Shopify theme editor where supported.

## Maison editorial hero

The hero supports:

- Separate desktop and mobile campaign images.
- Eyebrow, heading, and rich-text description.
- Primary and secondary buttons with links.
- Content position and text alignment.
- Image overlay opacity.
- Desktop hero height.
- Optional scroll indicator.

The default desktop height is 680px. The default content position and text alignment are left. The default overlay opacity is 55%.

Use appropriately cropped campaign imagery. Preview the mobile image separately on narrow screens.

## Featured collections

Configure the eyebrow, heading, description, desktop columns, and product count visibility. Add collection blocks and select the collections to feature.

The default desktop column count is 3, adjustable from 2 to 5.

## Maison new arrivals

Choose a product collection and configure:

- Number of products: 4, 6, or 8.
- Secondary product image on hover.
- View-all link and label.
- Quick add for single-variant products.
- Sale and sold-out badge labels.

## Maison brand story

Configure the image, image position, eyebrow, heading, description, and button.

The image can appear on the left or right.

## Maison lookbook

Use campaign blocks to build an editorial lookbook. Configure the section eyebrow, heading, and description, then add and arrange campaign blocks in the theme editor.

## Maison newsletter

Configure the eyebrow, heading, description, email placeholder, button label, and footnote.

The newsletter form uses Shopify's customer subscription functionality. Ensure your store's customer marketing settings are configured appropriately.

## Header

The header supports:

- Announcement text and link.
- Logo and logo width.
- Navigation menu.
- Sticky header.
- Search, account, and cart visibility.

The default logo width is 160px.

## Footer

The footer supports a logo, brand name, description, three navigation menus, social links for Instagram, Pinterest, TikTok, and Facebook, copyright text, payment icons, and policy links.

Add your store's menus and social URLs in the theme editor.
